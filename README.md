# UIUC Enrollment Demographic Analysis (1968–2016)

## Project Overview

This project analyzes historical student enrollment trends at the University of Illinois Urbana-Champaign (UIUC) from 1968 to 2016 using Python.

The goal is to understand how student demographics changed over time, identify major trends, and compare enrollment patterns across different demographic groups.

This project builds on my earlier research into African American and Caucasian student enrollment at UIUC and expands the analysis to include five demographic groups.

## Research Questions

1. How did UIUC's student demographic composition change between 1968 and 2016?
2. Which demographic groups experienced the largest changes in enrollment share?
3. How did demographic trends vary across different time periods?
4. What inconsistencies exist in the historical enrollment data?

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Visual Studio Code

## Dataset

The dataset contains historical fall-semester enrollment records from 1968 through 2016.

The analysis focuses on five reported demographic categories:

- African American
- Asian American
- Hispanic
- Caucasian
- International

It also examines enrollment by academic level: undergraduate, graduate, and professional.

## Analysis

The project includes:

- Data cleaning and preparation
- Exploratory data analysis
- Enrollment trends by academic level
- Demographic enrollment counts and percentages
- Comparisons between 1968 and 2016
- Average annual changes across different time periods
- Data quality and consistency checks

## Key Findings

Between 1968 and 2016:

- Caucasian enrollment share decreased from 79.60% to 43.94%.
- International enrollment share increased from 3.63% to 23.84%.
- Asian American enrollment share increased from 1.21% to 14.78%.
- Hispanic enrollment share increased from 0.45% to 8.80%.
- African American enrollment share increased from 2.68% to 5.16%.

These findings demonstrate substantial changes in UIUC's reported student demographic composition over the study period.

## Limitations

The analysis identified discrepancies in historical enrollment records, including differences in 1989 and 2016.

Additionally, demographic reporting categories may have changed over time, potentially affecting comparisons between years.

The project focuses on describing historical trends rather than establishing their causes.
